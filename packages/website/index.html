The Git GUI that

A visual Git client for repositories on your machine and on remote servers over SSH. No agent to install, no copying code around — just your SSH access.

Everything you reach for every day

Built out of necessity: a GitKraken-style workflow that also works on the repository on your server.

Remote repositories over SSH

Open a repository on any server you can ssh into and work with it like a local one. GitYak uses your system SSH with its keys, agent and ~/.ssh/config, reuses one connection for every command, and supports jump hosts (ProxyJump). Nothing has to be installed on the server.

Commit graph

Branches, merges and tags drawn as a graph, with search, multi-select and paging that keeps even very long histories fast.

Stage by hunk

Stage, unstage or discard whole files or single hunks right in the side-by-side diff.

Interactive rebase

Reorder, squash, reword and drop commits in a dialog instead of a todo file. Drag a branch onto another to merge or rebase.

Conflict resolver

Pick ours or theirs for each conflict, side by side, and see the result before you continue the merge or rebase.

Image diffs

PNG, JPG, GIF, WebP and SVG changes shown before and after, with synced zoom and pan.

Stash, cherry-pick, tags

The everyday operations a right-click away, plus file history and blame.

Command palette

Every action and project is a few keystrokes away; keyboard shortcuts for the frequent ones.

Themes

A set of built-in themes, including a colour-blind friendly light one, and a live editor for your own.

Templates

Commit message prefixes and branch name templates, globally or per project.

All your projects

Local and remote repositories side by side, one click apart. A gityak:// link adds a project from anywhere.

Desktop or browser

A native app for macOS, Windows and Linux, or a small local server and any browser.

Activity log

Every git command GitYak runs, with its output, so nothing happens behind your back. Hook output included.

See what changed — even in images

Text changes open in a full side-by-side editor. Images get a preview of both versions with a checkerboard background for transparency; zoom in to compare single pixels.

macOS

GitYak is not signed with an Apple Developer ID yet, so macOS blocks the first start. Open the .dmg, drag GitYak to Applications, then either right-click it and choose Open, or run: 

xattr -cr /Applications/GitYak.app

Ubuntu / Debian

Install the package with apt, which also installs git and the SSH client when they are missing:

sudo apt install ./GitYak-*-linux-x64.deb

On Ubuntu 20.04 use the Ubuntu 20.04 package; it is built for its older system libraries.

Windows beta

Windows SmartScreen may warn about an unknown publisher: choose More info → Run anyway. GitYak needs Git for Windows. The Windows build is new and less tested than the others.

GitYak checks for new versions on startup and tells you when one is available (you can turn this off in Settings).
